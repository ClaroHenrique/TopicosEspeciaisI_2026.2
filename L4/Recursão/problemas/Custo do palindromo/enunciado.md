# Menor quantidade de trocas para formar um palíndromo

Dada uma string, você deve determinar o menor número de letras que precisam ser trocadas para que ela se torne um palíndromo. Cada troca consiste em alterar um caractere da string para qualquer outra letra.

Sua tarefa é implementar uma função recursiva que calcule esse valor.

---

## Entrada

A primeira e única linha da entrada contém uma string $S$ formada por letras minúsculas do alfabeto, com tamanho entre $1$ e $100000$.

---

## Saída

Imprima um único inteiro: o menor número de trocas necessárias para transformar a string em palíndromo.

---

## Exemplos

### Exemplo 1

**Entrada:**
```text
abxca
```

**Saída:**
```text
1
```

---

### Exemplo 2

**Entrada:**
```text
osso
```

**Saída:**
```text
0
```
