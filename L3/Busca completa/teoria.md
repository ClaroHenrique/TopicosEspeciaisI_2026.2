# Busca completa


Como o nome sugere, a busca completa consiste em testar todas as soluções possíveis e verificar qual delas é a correta. 

Alguns problemas exigem apenas encontrar uma solução qualquer que satisfaça os critérios. Outros problemas podem pedir para encontrar uma melhor solução dentro de todas as soluções possíveis, chamamos esses de *problemas de otimização*. Outro tipo de problema pode pedir quantas soluções existem, nesse caso dizemos temos um *problema de contagem*.

# Busca na resposta

Em problemas de otimização, a busca pode ser realizada tanto nas soluções, quanto na resposta da solução. As vezes é mais fácil testar se uma resposta é possível de ser alcançada, do que encontrar a solução diretamente.

Nesses casos, você pode se perguntar:

* Se tivermos a resposta, é mais fácil verificar se ela é a certa?
* A complexidade permite testar todas as respostas?
