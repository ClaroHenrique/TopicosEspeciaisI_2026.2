# Raiz quadrada inteira

Sua tarefa é responder uma série de consultas para calcular a raiz quadrada inteira de determinados números. A raiz quadrada inteira de um número $N$ é o maior inteiro $x$ tal que $x^2 \leq N$.

O desafio é não usar funções já prontas da linguagem!

## Entrada

A primeira linha da entrada contém um inteiro $Q$ ($1 \leq Q \leq 10^4$), indicando a quantidade consultas que você deve processar. Cada uma das próximas $Q$ linhas contém um número também inteiro $A_i$ ($0 \leq A_i \leq 10^{9}$), que você deve calcular a raiz quadrada inteira.

## Saída

Para cada consulta, responda qual a raiz quadrada daquele número.


## Exemplo

**Entrada**
```text
4
5
9
100
101
```

**Saída**
```text
2
3
10
10
```
