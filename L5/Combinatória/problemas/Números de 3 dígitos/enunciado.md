# Números de 3 dígitos


## Descrição

Dado um conjunto de dígitos, você deve deve calcular quantos números válidos de 3 dígitos podem ser formados. Note que é permitido repetições e um número válido de 3 dígitos não pode começar com o dígito 0. Por exemplo, 121 é um número válido de 3 dígitos, mas 003 não é.

## Entrada

A primeira linha da entrada contém um inteiro N, a quantidade de dígitos disponíveis. A segunda linha contém N dígitos distintos, separados por espaço.

## Saída

Seu programa deve imprimir um único inteiro, indicando a quantidade de números contados.

## Restrições

* $1 \leq N \leq 10$
* Os dígitos são números entre 0 e 9.


## Exemplo 1

**Entrada**
```text
3
1 2 3
```

**Saída**
```text
27
```


## Exemplo 2

**Entrada**
```text
2
0 1
```

**Saída**
```text
4
```
